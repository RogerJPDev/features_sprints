HTML

Aquí tienes una guía rápida para escribir HTML moderno y semántico: estructura, meta, texto, enlaces, listas, multimedia, tablas, formularios, accesibilidad y buenas prácticas.

Document skeleton

Boilerplate


                <!DOCTYPE html>
                <html lang="en">
                <head>
                  <meta charset="UTF-8">
                  <meta name="viewport" content="width=device-width, initial-scale=1.0">
                  <title>Page title</title>
                </head>
                <body>
                  <!-- visible content goes here -->
                </body>
                </html>

Elements, tags & attributes


                <p class="intro" id="lead">Hello, world!</p>
                <img src="cat.jpg" alt="A sleeping cat">
                <!-- self-closing / void elements have no closing tag -->
                <br>
                <hr>
                <input type="text">

Void elements


                <meta charset="UTF-8">
                <link rel="stylesheet" href="styles.css">
                <img src="logo.png" alt="Logo">
                <input type="text">

Boolean attributes


                <input type="text" disabled>
                <input type="checkbox" checked>
                <video src="clip.mp4" controls autoplay muted loop></video>
                <script src="app.js" defer></script>

Comments & the lang attribute


                <!-- this is a comment, the browser ignores it -->
                <html lang="en">
                <html lang="es">
                <p lang="fr">Bonjour!</p> <!-- override for one element -->

Text & structure

Headings & paragraphs


                <h1>Main title</h1>
                <h2>Section title</h2>
                <h3>Subsection</h3>
                <p>A paragraph of text.</p>

Lists


                <ul>
                  <li>Unordered item</li>
                  <li>Another item
                    <ul><li>Nested item</li></ul>
                  </li>
                </ul>

                <ol start="3" reversed>
                  <li>Ordered item</li>
                  <li>Another</li>
                </ol>

                <dl>
                  <dt>HTML</dt>
                  <dd>The markup language of the web.</dd>
                </dl>

Links & images


                <a href="https://example.com" target="_blank" rel="noopener">Visit site</a>
                <a href="#section-2">Jump to section</a>
                <a href="mailto:hi@example.com">Email us</a>
                <a href="tel:+15551234567">Call us</a>
                <img src="photo.jpg" alt="Description of photo" width="400" loading="lazy">

Inline text semantics


                <strong>Important text</strong>
                <em>Stressed emphasis</em>
                <code>inline code</code>
                <mark>Highlighted text</mark>
                <abbr title="HyperText Markup Language">HTML</abbr>
                H<sub>2</sub>O  x<sup>2</sup>
                <time datetime="2026-09-18">September 18, 2026</time>

Blockquote, pre & figure


                <blockquote cite="https://example.com">
                  <p>A quoted passage.</p>
                </blockquote>

                <pre><code>function greet() {
                  return "hi";
                }</code></pre>

                <figure>
                  <img src="chart.png" alt="Quarterly revenue chart">
                  <figcaption>Revenue grew 12% in Q3.</figcaption>
                </figure>

Tables


                <table>
                  <caption>Quiz results</caption>
                  <thead>
                    <tr><th scope="col">Name</th><th scope="col">Score</th></tr>
                  </thead>
                  <tbody>
                    <tr><th scope="row">Ana</th><td>92</td></tr>
                    <tr><th scope="row">Leo</th><td>87</td></tr>
                  </tbody>
                  <tfoot>
                    <tr><td>Average</td><td>89.5</td></tr>
                  </tfoot>
                </table>

Forms

Basic form


                <form action="/submit" method="POST">
                  <label for="email">Email</label>
                  <input type="email" id="email" name="email" required>

                  <label for="msg">Message</label>
                  <textarea id="msg" name="msg" rows="4"></textarea>

                  <button type="submit">Send</button>
                </form>

                <input type="text">

                <input type="range" min="0" max="100" step="5">
                <input type="color">
                <input type="tel">
                <input type="url">
                <input type="search">
                <input type="checkbox" checked>
                <input type="radio" name="plan">
                <input type="date">

                <select>

Grouping & autocomplete


                <fieldset>
                  <legend>Shipping address</legend>
                  <label for="city">City</label>
                  <input id="city" name="city" list="cities" autocomplete="address-level2">
                  <datalist id="cities">
                    <option value="Barcelona">
                    <option value="Madrid">
                  </datalist>
                </fieldset>

Validation attributes


                <input type="text" required minlength="3" maxlength="20">
                <input type="number" min="1" max="100" step="1">
                <input type="text" pattern="[A-Za-z]+" title="Letters only">
                <input type="email" required>

                <style>
                  input:invalid { border-color: red; }
                  input:valid { border-color: green; }
                </style>

Semantic layout

Page regions


                <header>Site header / logo / nav</header>
                <nav>Main navigation</nav>
                <main>
                  <article>
                    <section>A self-contained chunk of content</section>
                  </article>
                  <aside>Related links, sidebar</aside>
                </main>
                <footer>Copyright, links</footer>

div vs span


                <div class="card">
                  <span class="badge">New</span> Block of content
                </div>

Disclosure & dialog


                <details>
                  <summary>Click to expand</summary>
                  <p>Hidden content revealed on click.</p>
                </details>

                <dialog id="modal">
                  <p>Are you sure?</p>
                  <button onclick="document.getElementById('modal').close()">Close</button>
                </dialog>
                <button onclick="document.getElementById('modal').showModal()">Open</button>

Address & article metadata


                <article>
                  <h2>Blog post title</h2>
                  <p>By <address style="display:inline">Ana Lopez</address></p>
                  <time datetime="2026-09-01">September 1, 2026</time>
                  <p>Post content...</p>
                </article>

Media & embedding

Video & audio


                <video width="480" controls poster="thumb.jpg">
                  <source src="clip.mp4" type="video/mp4">
                  <track kind="captions" src="captions.vtt" srclang="en" label="English">
                  Your browser doesn't support video.
                </video>

                <audio controls>
                  <source src="song.mp3" type="audio/mpeg">
                </audio>

Responsive images with srcset & picture


                <img
                  src="photo-800.jpg"
                  srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1200.jpg 1200w"
                  sizes="(max-width: 600px) 400px, 800px"
                  alt="Mountain view">

                <picture>
                  <source media="(min-width: 800px)" srcset="wide.jpg">
                  <source type="image/webp" srcset="photo.webp">
                  <img src="photo.jpg" alt="Mountain view">
                </picture>

Inline SVG, canvas, iframe


                <svg width="24" height="24" viewBox="0 0 24 24">
                  <circle cx="12" cy="12" r="10" fill="currentColor" />
                </svg>

                <canvas id="chart" width="300" height="150"></canvas>

                <iframe src="https://example.com" width="600" height="400"
                        loading="lazy" title="Embedded content"></iframe>

Browser storage & APIs

localStorage & sessionStorage


                localStorage.setItem('theme', 'dark');
                const theme = localStorage.getItem('theme');
                localStorage.removeItem('theme');

                sessionStorage.setItem('draft', JSON.stringify({ text: 'hi' }));
                const draft = JSON.parse(sessionStorage.getItem('draft'));

Drag and drop


                <div draggable="true" ondragstart="event.dataTransfer.setData('text', 'card-1')">
                  Drag me
                </div>
                <div ondrop="drop(event)" ondragover="event.preventDefault()">
                  Drop here
                </div>

Resource hints & lazy loading


                <link rel="preload" href="font.woff2" as="font" crossorigin>
                <link rel="preconnect" href="https://api.example.com">
                <img src="below-the-fold.jpg" alt="..." loading="lazy">
                <script src="app.js" defer></script>

Advanced & accessibility

data-* attributes


                <button data-user-id="42" data-role="admin">Edit</button>

                <script>
                  const btn = document.querySelector('button');
                  console.log(btn.dataset.userId); // "42"
                </script>

ARIA & accessibility


                <button aria-label="Close dialog">&times;</button>
                <div role="alert">Your changes were saved</div>
                <nav aria-current="page">...</nav>
                <img src="chart.png" alt="" role="presentation">
                <button aria-expanded="false" aria-controls="menu">Menu</button>
                <input aria-describedby="pw-help">
                <p id="pw-help">Must be 8+ characters</p>

Meta tags for SEO & sharing


                <meta name="description" content="Short page summary for search results">
                <meta property="og:title" content="Page title">
                <meta property="og:image" content="preview.jpg">
                <meta property="og:type" content="website">
                <meta name="twitter:card" content="summary_large_image">
                <link rel="canonical" href="https://example.com/page">
                <link rel="icon" href="favicon.ico">

Structured data (JSON-LD)


                <script type="application/ld+json">
                {
                  "@context": "https://schema.org",
                  "@type": "Article",
                  "headline": "How to learn HTML",
                  "datePublished": "2026-09-01"
                }
                </script>

<template> and web components


                <template id="row-template">
                  <tr><td class="name"></td><td class="score"></td></tr>
                </template>

                <my-widget title="Hello"></my-widget>

                <script>
                  class MyWidget extends HTMLElement {
                    connectedCallback() {
                      const shadow = this.attachShadow({ mode: 'open' });
                      shadow.innerHTML = `<style>p{color:blue}</style>
                        <p>${this.getAttribute('title')}</p>`;
                    }
                  }
                  customElements.define('my-widget', MyWidget);
                </script>
